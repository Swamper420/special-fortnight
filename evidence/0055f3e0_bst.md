## 1. Claim

`FUN_0055f3e0` is a binary-tree walk keyed on wide-string compare.
Calling convention (observed): `ECX` = node+`0x14` context
(passthrough from `0055e910`, which holds `ECX` = node+`0x14`),
one stack param = key (`RET 0x4`; caller does `PUSH EDI`/key then
`CALL`, `0055e910` `0x55e931-0x55e932`). Returns a node pointer in
`EAX`: the last node on the walk where the compare returned zero,
or the initial `[ECX+4]` when the tree is empty. It never returns
a miss flag — miss/duplicate semantics reduce to "which node the
walk records last", and the compare's argument order (key vs
candidate first) is still unmapped, so tree direction and
equal-key behavior stay open (U1).
