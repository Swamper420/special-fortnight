## 2. Pseudocode (inference, asm-exact, branch order kept)

```c
float __thiscall slot1_4434d0(ArcElem *ECX, float x)
{
  float t1 = square(ECX->f20 /* +20 */);   // 0x443290: v*v
  float t2 = square(x - ECX->f12 /* +12 */);
  float d = t1 - t2;
  float s;
  if (d >= 1e-5f)           // FCOMP 1e-5f; FNSTSW/TEST AH,1; JZ (C0==0)
    s = /* recompute d */ d;  // JZ block recomputes d (FCOMP popped it)
  else                      // d < 1e-5f, or unordered (NaN)
    s = 1e-5f;              // FLD [0x005ce11c]
  // merge: num = (x - f12) * (int32)i24 (FIMUL, exact); FXCH; sqrt;
  // FXCH x2 (no-op); FDIVP:
  return (float)((x - ECX->f12) * (int32)ECX->i24) / sqrt(s);
}
```

Shape: `y = n*(x-cx)/sqrt(s)` with `s = d if d >= 1e-5 else 1e-5`,
`d = square(r) - square(x - cx)`. This is exactly `dy/dx` of the
slot-0 curve `y = cy - n*sqrt(d)` (CHECKED inference: `d/dx`
`-n*sqrt(d)` = `-n*(-(x-cx)/sqrt(d))` = `n*(x-cx)/sqrt(d)`), with an
epsilon clamp so the divisor never drops below `sqrt(1e-5)` — no
`sqrt(negative)`, no divide-by-zero on ordered inputs.

## 3. NaN paths (observation: one compare, one branch)

`FLD`/`FSTP` move NaN bit-exact. `FSUB`/`FMUL`(helper)/`FSUBR`
propagate: QNaN in → QNaN out. Net:

- NaN in any of `{x, f12, f20}` → `d` NaN → `FCOMP` unordered
  (C0=C2=C3=1) → `TEST AH,1` nonzero → `JZ` NOT taken → clamp path
  (`s = 1e-5f`), then the merge `FSUB`/`FIMUL` re-derives NaN into
  the numerator iff `x` or `f12` is NaN:
  - NaN `x` or NaN `f12` → numerator NaN → `y` NaN (poison).
  - NaN `f20` only → `d` NaN clamps, numerator ordered → FINITE
    result `(x-cx)*n/sqrt(1e-5)` — NaN `r` does NOT poison.
- NaN in `f16` (`cy`): field never read → NO effect (contrast
  slot 0, which poisons via `FSUBR`).
- Ordered inputs: divisor `>= sqrt(1e-5) > 0` always — result is
  finite except via NaN numerator (above). `±inf` never occurs.
- `d = +inf` (overflow via `FSTP m32` saturation — masked-overflow
  behavior is inference): ordered, `JZ` taken, `sqrt(+inf)=+inf`;
  finite numerator → `±0`.
- `n == 0` (unreachable via ctor, which throws — cited): numerator
  `±0` → `±0/sqrt(s)` = `±0`.
