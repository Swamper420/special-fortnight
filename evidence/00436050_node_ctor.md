## 1. Claim

`FUN_00436050` constructs the stairs (`+0x21c`-family) node in place
(`ECX` = node base, returns base in `EAX`). Proven layout, exact fit
`0x10 + 2*0x24 = 0x58`:

- `+0x0/+0x4/+0x8/+0xc`: 4 dwords, zeroed here, overwritten right after
  by `FUN_00436020` with the parsed floats (`l1,l2,z1,z2` ordering
  still per parent U1, not re-proven here).
- `+0x10..+0x33`: first payload object (0x24 bytes), via `FUN_00435cc0`.
- `+0x34..+0x57`: second payload object (0x24 bytes), via `FUN_00435cc0`.

Each `FUN_00435cc0` object (0x24 bytes) holds two 0x10-byte
string-shaped blocks plus a trailing dword: block A at `+0x00`
(byte at `+0x0`, dwords at `+0x4/+0x8/+0xc`), block B at `+0x10`
(byte at `+0x10`, dwords at `+0x14/+0x18/+0x1c`), dword at `+0x20`
(zeroed). Block A defaults to `Textures\wood1.png`, block B to
`Materials\material1.txt`. The dword roles inside each block
(ptr vs length vs capacity) and the meaning of `+0x20` are NOT proven
(see Unknowns). No engine code edits: nothing here is pure
(allocator + string-assign callees, SEH); no Rust transcribed.

## 4. Sibling cross-check (size arithmetic, proven)

`FUN_00436550` (`ev_e238...`, 28 bytes) is the `0x34`-node ctor:
`LEA ECX,[ESI+0x10] / CALL 00435cc0` once, then zero

payload object), matching `0x58 = 0x10 + 2*0x24` here

by both offsets, not assumed. Remaining sibling ctors

## 5. Inference (labeled)

- Each 0x10-byte block smells like `{u8 flag; pad[3]; ptr; len; cap?}`
  (Borland/string-ish): byte + 3 dwords, NUL-terminated word copies,
  grow guard `00403a40/0059c12b`, assign helpers. But which dword is
  length vs capacity (`+0x8` written with `EBP` in both blocks;
  `+0xc` only read in the `0x1f`-capacity check at `0x435db2–0x435dbc`)
  is inference from one read — NOT proven.
- `+0x20` (zeroed, never touched afterward in either function) is
  likely an index/enum/flags field — pure guess.
- The two payload objects in one node likely correspond to two
  textured/material slots (wood texture + material file defaults),
  but no caller ever overrides them in the observed leaf path —
  inference only.
