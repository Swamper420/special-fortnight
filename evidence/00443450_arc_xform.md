## 2. Pseudocode (inference, asm-exact, branch order kept)

```c
float __thiscall xform_443450(ArcElem *ECX, float x)
{
  float t1 = square(ECX->f20 /* +20 */);   // 0x443290: v*v
  float t2 = square(x - ECX->f12 /* +12 */);
  float d = t1 - t2;
  float s;
  if (d >= 0.0f)          // FCOMP +0.0; FNSTSW/TEST AH,1; JZ (C0==0)
    s = sqrt(d);          // JZ block recomputes d (FCOMP popped it)
  else                    // d < 0, or unordered (NaN)
    s = sqrt(0.0f);       // = +0.0
  return ECX->f16 /* +16 */ - (float)(int32)ECX->i24 /* +24 */ * s;
}
```

Shape: `y = f16 - i24*sqrt(max(d, 0))` with
`d = square(f20) - square(x - f12)`. Negative-`d` (outside radius)
clamps to `f16 ∓ 0` instead of raising invalid from `FSQRT` — the
`FCOMP`/`JZ` exists exactly to dodge `sqrt(negative)`. Range gating
stays the selector's job, same split as linear/cubic.

## 3. NaN paths (observation: one compare, one branch)

`FLD`/`FSTP` move NaN bit-exact. `FSUB`/`FMUL`(helper)/`FSUBR`
propagate: QNaN in → QNaN out. Net:

- NaN in any of `{x, f12, f20}` → `d` NaN → `FCOMP` unordered
  (C0=C2=C3=1) → `TEST AH,1` nonzero → `JZ` NOT taken → clamp path →
  `y = f16 - i24*0`. **NaN maps to `f16 ∓ 0`** — contrast linear/cubic,
  which poison through. (SNaN: first `FSUB`/`FMUL` raises
  invalid → QNaN under default masked control word — control word value
  is inference from standard runtime setup, not observed in-body.)
- NaN in `f16` → `FSUBR` NaN → `y` NaN on both paths (poison).
- `i24 = 0`, `d > 0`: `sqrt(d)*0 = ±0` → `y = f16 ∓ 0`.
- `d = +inf` (overflow via `FSTP m32` saturation to `±inf` on the stash
  stores — masked-overflow behavior is inference): ordered, `JZ` taken,
  `sqrt(+inf)=+inf`; `i24>0` → `-inf`, `i24<0` → `+inf`, `i24==0` →
  `inf*0` invalid → NaN.
- `-0.0` edge: `d == -0.0` compares equal → `JZ` taken →
  `sqrt(-0)= -0` → `y = f16 ∓ 0`.

  result stays 80-bit in `ST0` — no `FSTP m32` before `RET`. Rust `f32`
  transcription rounds the final `FSUBR` to `f32`; last-ulp borderlines
  can differ. Additionally `FIMUL` multiplies the exact int32 value in
  80-bit while Rust `n as f32` rounds `|n| > 2^24` first — same caveat
  class, NOT fixed here.
