## Verification

- Assembly comparison: Rust in `src/fn_00401e74.rs` keeps the small
  lane fully (`esize-4` compare, `max` grow math with wrapping,
  `param_2*4+0x40` fit check, `0x40a2c` header-write gate, indirect
  copy + free order, shrink alloc/copy/free order), the tag dispatch
  (`&7/&5/&3→null`), heap-lane pure early-outs (`2×` fit,
  `0xb2c`/`0x2cc` floors, tiny alloc/copy/free lane), and delegates
  lock/body regions to hooks.
- Unit test: single sequential test covers small fit/grow (incl. max
  math and `0x40a2c` gate)/shrink-null/shrink-ok, dead tag → null,
  heap fit → identity, tiny lane copy/free order, chunk/heap-split
  hook routing. Verified: `cargo test` 110 pass,
  `cargo build --target i686-pc-windows-gnu` clean (integrated batch).
- Note: small-lane `desc` is a double-deref (`MOV EBX,[ECX] /
  MOVZX ECX,[EBX+2]`); test helper models desc[0]→table, esize at
  table+2. Heap-split vector uses hdr `0x3002` (have `0x2ffc` =
  `2×` gate) since `0x2002`/`0x1000` is a fit (`have ≤ 2×want`).
- Harness (i686 target first-compile): the helper 8-aligns the
  arena start before applying the fixed `+16/+32/+48` relative
  layout. 64-bit hosts align `[u64; 12]` to 8 for free; 32-bit
  hosts align it to 4 only, which broke the `hdrp & 7 == 0` tag
  assert. Relative layout (and 64-bit addresses) unchanged.
