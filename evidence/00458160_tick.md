`FSUBR m32`: `ST0 = cur − ref`; `FABS`; `FCOMP` 1.0-double sets C0 iff
`ST0 < 1.0` or unordered; `TEST AH,1`/`JZ` skips the store iff C0 clear,
i.e. stores `cur + 0.75f` iff `|cur − ref| < 1.0` or either side NaN
(unordered → C0 set → nudge; NaN `cur` → NaN, NaN `ref` → `cur + 0.75`).
Transcribed as
`nudge_075` in `engine/src/fn_00458160.rs` with one test (exact f32
cases + both NaN sides).
