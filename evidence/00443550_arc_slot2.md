## 2. Pseudocode (inference, asm-exact)

```c
float __thiscall slot2_443550(ArcElem *ECX, float x /* ignored */)
{
  return (float)(ECX->i24 /* +24 */) * (ECX->f20 /* +20 */);
}
```

`FILD` converts the exact int32 to 80-bit; `FMUL m32` multiplies by
the float `r` in 80-bit; the unrounded `ST0` returns (`RET`, no
`FSTP m32`).

Role (INFERENCE, one step, checked against the step-loop evidence):
slot+8 feeds the emitter rate — `mag = |slot8(x)*0.025|` clamped to
`10.0`, `x' = cos(atan(slot4(x)))*mag + x` (`004ddcb0_stepping.md`
§2; `004ddf10` single-call variant). For arc the rate is the
x-independent constant `n*r`, so step length scales with radius.
`n ∈ {-1,+1}` via ctor (cited slot+4 evidence §5); sign only flips
`mag`'s pre-`FABS` sign — magnitude-identical.

## 3. NaN paths (observation: no compare, no branch)

`FILD` takes an int32 — never NaN. `FMUL` propagates: QNaN in → QNaN
out. Net:

- NaN `r` (`+20`) → NaN result (poison, sole NaN source).
- NaN `x` or NaN `+12`/`+16`: fields never read → NO effect
  (contrast slots 0/`+4`, where NaN `x` poisons).
- Ordered inputs: finite except via NaN `r`. `±inf` only via
  `f32`-range overflow of `|n|*|r|` (80-bit holds it finite —
  divergence note, U1).
- `n == 0` (unreachable via ctor, which throws — cited): `+0 * r`
  = `±0` (`FILD 0` = `+0`).
