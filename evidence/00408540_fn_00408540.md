Count/branch notes: `DEC EDX` wraps (`wrapping_sub`); the three
`SUB/JNC/ADD/XOR` groups are saturating `min(requested, capacity)`
idioms (`count_used = min(ECX, EDX); EDX -= count_used`); each `REP`
leaves `ECX=0`, which the `XCHG` pair relies on. `END` is
`param_3 + param_6*2` bytes (`LEA ECX,[ESI+ECX*2]`, signed `param_6`).
`PUSH ECX/PUSH EDX … POP EDX/POP ECX` is a save pair (both values are
consumed after restore: `EDX` by the phases, `ECX` as `END` at the
loop-back compare), not callee stack args — a caller cleaning up
plain args would use a single `ADD ESP,8`.
