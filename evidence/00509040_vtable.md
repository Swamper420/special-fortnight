## 1. Claim

- `FUN_00509040(a, b)` is the **start/play** arm: liveness-guard
  (`0040e500` on `[ECX+0x20]`, silent return if zero) → `00509160()`
  status poll → conditional `005091e0()` buffer setup (iff status nonzero)
  → vtable slot `+0x30` of `[ECX+0x24]` with
  `(inner, 0, a, (b != 0) | 0x20)`; negative vtable return throws
  `CMExceptionDSBuffer` via `005090b0` + `__CxxThrowException`.
  `RET 0x8` = two stack args.
- `FUN_005090e0()` is the **stop** arm: same liveness-guard →
  `00509110()` (stop-guard + vtable `+0x48`) → `00509410(0)`
  (vtable `+0x34` with 0). `RET` = no args.
- Both are methods on the same DirectSound-buffer wrapper class as
  `00509390`/`005092c0` (same `+0x20` guard object / `+0x24` inner vtable
  object / `005090b0` throw path — observation of shared plumbing, not a
  class-recovery claim). No API-level claim (vtable slots indirect,
  owners unmapped).

## 6. Inference

- Role: transport controls on the DS-buffer wrapper — `00509040(a,b)`
  starts playback (status check + conditional buffer fill + play call
  with loop-ish flag `(b!=0)|0x20`), `005090e0()` stops it
  (guarded stop + zero forward). The `(b!=0)|0x20` flag bit and
  `+0x30/+0x34/+0x48` vtable slots are indirect with unmapped owners,
  so no `Play/Stop` API-level claim is made.
- `004586a0` §4 dispatch now reads: `== 1 → start(a,b)` with per-idx
  pairs, `== 2 → stop()`. The `0xa`-skip and `DAT_0061b8a8 ∈ {8,9}`
  mode meaning stay open (parent U5).
- `00509040` has notably wider caller fan-out (23) than the rate/level
  setters — start is shared across engine paths; each caller unexamined.

## 7. Transcription decision: evidence only (no code)

- No clean pure fragment: `(b != 0) | 0x20` is three instructions
  (`TEST/SETNZ/OR`) but inseparable from the indirect `+0x30` forward
  (unmapped target) and the `00509160/005091e0` setup chain — a
  transcribed `flags()` one-liner would duplicate the throw/guard
  plumbing without any runnable check against the real vtable.
- `005090e0` is pure plumbing (guard → guard → forward-zero), nothing
  to transcribe.
- 1:1 reuse check: `engine/src` has no `509040/5090e0` fragment (grep
  clean); dispatch pairs and clamp fragments stay in
  `engine/src/fn_004586a0.rs`, not duplicated here.
